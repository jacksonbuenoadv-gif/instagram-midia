# instagram-midia

Hospedagem pública das imagens do Instagram @jacksonbueno.adv (Jackson Bueno Advogados, OAB/MG 211.217).

- `posts/AAAA-MM-DD/` – slides do carrossel do dia (`slide1.jpg`…), `story.jpg`, `legenda.txt` e `spec.json`.
- `ferramentas/gerar.py` – gerador das artes na identidade visual do site jacksonbueno.adv.br (instruções no cabeçalho do arquivo).
- `fotos/` – banco de fotos reais (próprias ou de bancos com licença de uso comercial). Registre a origem de cada foto em `fotos/CREDITOS.md`.

Links públicos: `https://raw.githubusercontent.com/jacksonbuenoadv-gif/instagram-midia/main/<caminho>`
